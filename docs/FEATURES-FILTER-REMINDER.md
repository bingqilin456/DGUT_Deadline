# 筛选与提醒功能说明

本文档记录 **2026-11-08 新增** 的两组功能，均为用户明确提出的需求。

---

## 一、作业列表筛选

### 1.1 默认行为（用户指定）

| 行为 | 实现 |
|---|---|
| **默认只看未截止** | `hideExpired: true` |
| **默认按截止时间最近优先** | `sort: 'dueAsc'`，无截止时间的排末尾 |

截图：`docs/screenshots/filter-default.png`

### 1.2 可筛选维度（5 项 + 搜索 + 排序）

| 维度 | 选项 |
|---|---|
| **平台** | 全部 / 作业平台 / 优学院 |
| **课程** | 全部 / 具体课程（从数据自动提取，按拼音排序）|
| **截止时间** | 不限 / 今天内(24h) / 3天内 / 7天内 / 30天内 / 已截止 / 时间待确认 |
| **剩余** | 不限 / 3小时内 / 24小时内 / 72小时内 / 7天内 / 无截止时间 |
| **状态** | 全部 / 未提交 / 已提交 / 状态待确认 / 已截止 |
| 搜索 | 标题 + 课程名，大小写不敏感 |
| 排序 | 截止最近优先 / 最远优先 / 按课程 |

### 1.3 交互细节

- 选中「截止时间 = 已截止」时**自动关闭**「隐藏已截止」，避免条件互相矛盾
- 显示「显示 X / Y 条」，并在隐藏了过期项时提示「已隐藏 N 条已截止」
- 「重置筛选」按钮在非默认状态时才可用
- 筛选后无结果时有专门空状态，提示「共 N 条作业，被筛选条件排除了」

### 1.4 实现与测试

| 项 | 位置 |
|---|---|
| 纯逻辑（筛选/排序/计数） | `src/renderer/src/logic/filter.ts` |
| 单元测试 | `src/renderer/src/logic/filter.test.ts`（**35 个用例**）|
| UI 组件 | `src/renderer/src/components/FilterBar.vue` |
| 端到端验证 | `scripts/filter-e2e.mjs`（真实 UI 交互） |

## 二、临近截止的强制提醒

### 2.1 默认阈值配置（用户指定）

| 提前 | 启用 | 强制弹出 | 说明 |
|---|---|---|---|
| 72 小时 | ✅ | ❌ | 普通提醒 |
| 24 小时 | ✅ | ❌ | 普通提醒 |
| **12 小时** | ✅ | ✅ | **强制** |
| **6 小时** | ✅ | ✅ | **强制** |
| **3 小时** | ✅ | ✅ | **强制** |
| **1 小时** | ✅ | ✅ | **强制** |

### 2.2 「强制弹出」的含义

- 弹出**桌面右下角自定义窗口**，必须点「我已知晓」才消失
- 主窗口**任务栏图标闪烁**（每 15 秒重复，直到确认）
- 弹窗每 20 秒重新置顶，防止被其他窗口盖住
- **不受静默时段限制**（普通提醒在静默时段内会被抑制，强制提醒不会）
- 红色边框 + ⚠️ 图标 + 紧迫措辞（如「⚠️ 还有 3 小时截止」「⚠️ 1 小时内截止！」）

截图：`docs/screenshots/toast-popup.png`

### 2.3 用户可逐项开关（用户指定）

设置页「提醒阈值」表格中，每一项都有两个勾选框：

| 勾选 | 效果 |
|---|---|
| **启用** | 关闭后该阈值完全不提醒 |
| **强制弹出** | 开启后弹窗 + 任务栏闪烁 + 不受静默限制 |

- 关闭「启用」时，「强制弹出」自动禁用
- 可删除任意阈值（至少保留 1 个）
- 可新增自定义阈值（输入小时数后回车，≤12h 自动标记为强制）

### 2.4 确认机制（用户指定）

弹窗中每条提醒都有「我已知晓」按钮；多条时额外提供「全部已知晓（N 条）」。

- 点击后该卡片消失
- 全部确认后弹窗窗口自动关闭，任务栏停止闪烁
- **未确认的提醒会一直保留**，符合「等用户确认是否收到」的要求

### 2.5 与系统通知的关系

| 场景 | 行为 |
|---|---|
| 正常情况 | 右下角自定义弹窗（可要求确认） |
| 弹窗创建失败 | 自动降级为系统 Toast 通知 |
| 用户聚焦主窗口 | 停止任务栏闪烁，但弹窗仍保留直到确认 |

### 2.6 实现与测试

| 项 | 位置 |
|---|---|
| 阈值配置模型 | `src/shared/thresholds.ts` |
| 提醒规划（含 urgent 标记） | `src/main/reminder/planner.ts` |
| 右下角弹窗管理 | `src/main/reminder/toast-manager.ts` |
| 弹窗页面 | `src/renderer/toast.html` + `src/renderer/src/toast-main.ts` |
| 弹窗 preload | `src/preload/toast.ts` |
| 调度与静默例外 | `src/main/reminder/scheduler.ts` |
| 任务栏闪烁 | `src/main/index.ts`（`startTaskbarAttention`）|
| 单元测试 | `src/main/reminder/scheduler.test.ts`（新增 3 个强制提醒用例）|
| 端到端验证 | `scripts/toast-e2e.mjs` |

### 2.7 数据迁移

配置结构从 v1 升级到 v2：

```
v1: settings.thresholdsHours = [72, 24, 3]
v2: settings.thresholds = [
      { hours: 72, enabled: true, urgent: false },
      { hours: 24, enabled: true, urgent: false },
      { hours: 12, enabled: true, urgent: true },
      ...
    ]
```

`AppStore.migrate()` 会自动转换老配置；≤12h 的阈值视为强制提醒，并补齐新的默认强制阈值。
